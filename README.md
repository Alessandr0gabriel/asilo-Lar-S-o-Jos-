# ACPIC Lar Sao Jose - Site Institucional

Projeto voluntario academico desenvolvido para o Asilo Sao Jose (ACPIC - Associacao Comunitaria de Protecao aos Idosos de Colorado/PR).

Este trabalho foi construido como parte da formacao em Engenharia de Software na Universidade Uninga/PR, com foco em impacto social, acessibilidade e divulgacao das acoes da instituicao.

## Objetivo

Criar e manter um site institucional simples, moderno e responsivo para:

- apresentar a historia e a missao do Lar Sao Jose;
- divulgar campanhas e necessidades de doacao;
- facilitar o contato com a comunidade;
- fortalecer a visibilidade de um projeto social local.

## Como Executar

1. Abra a pasta do projeto no VS Code.
2. Abra o arquivo `html/index.html` no navegador.
3. Para melhor experiencia, use uma extensao como Live Server.

## Funcionalidades

- menu responsivo com hamburguer no mobile;
- modo escuro com alternancia por botao;
- paginas institucionais (inicio, sobre, galeria, doacoes, equipe e contato);
- destaque para campanhas e QR Code de doacao;
- layout moderno com foco em leitura e navegacao.
